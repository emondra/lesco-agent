LESCO-Agent

Agente + Skill + MCP · visor local

LESCO-Agent propone secuencias candidatas de entradas del Diccionario LESCO del CENAREC. No es un traductor validado y no sustituye a intérpretes humanos.

Caso demo-001 · configuración demo (instrucciones de B + Skill; el guardado requiere aprobación humana) · turnos del modelo = guion fijo, sin API · servidor MCP y política reales · carpeta temporal aislada.

MOTOR LOCAL DE REGLAS — NO ES UN LLM
Antes de activar el micrófono: el reconocimiento de voz lo hace el navegador y puede depender de servicios externos (por ejemplo, de Google o Microsoft), que reciben el audio. La demo no recibe ni guarda audio: solo el texto que usted confirme. La voz no puede aprobar operaciones.
